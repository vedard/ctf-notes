# CTF Notes

Personal knowledge base for CTF competitions: cross-category material at the top level, category-specific material under `cat/<category>/` (`pwn`, `web`, `mobile`, `forensic`, `crypto`, `rev`, `misc`, `osint`).

- `references.md` — useful links
- `snippets/`, `tools/`, `notes/` — cross-category commands, tool notes, reusable technique notes
- `cat/<category>/` — same folders per category, plus `templates/` and `references.md`

Directory meanings and conventions are documented in [AGENTS.md](AGENTS.md).
